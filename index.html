玩法说明

    

       这是一个「电子斗蛐蛐」

      实时战斗，没有回合。每个单位按自己的速度连续移动与出手，全场同时进行。

      它们有独立的性格（侵略 / 谨慎 / 团队 / 风险 / 记仇 ）、战略（速攻 / 消耗 / 斩首 / 风筝 / 铁壁 / 游击 ）
      与战术（集火 / 绕后 / 撤退 / 护友 / 拉开 ），会自行寻路、找掩体、绕后偷袭、撤退重整。


       每个角色有三种技能

      专属技能（本命，固定）＋职业技能（同职业可选 2 个）＋通用技能（人人可选 2 个）。
      在「配置  点单位」里自由搭配，共 226 种技能、41 武器 / 21 护甲 / 28 饰品（都带被动）。


       元素反应（团队配合）

      油 + 火 = 爆燃　
      湿 + 冰 = 冻结　
      湿 + 雷 = 感电（连锁）　
      毒 + 火 = 毒爆　
      冻结 + 物理 = 碎冰


       属性与抗性（为魔法世界而设计）

      17 种伤害类型（物理 / 火 / 冰 / 雷 / 毒 / 木 / 暗影 / 神圣 / 奥术 / 音波 / 土 / 风 / 金 / 水 / 虚空 / 血噬 / 精神）＋
      11 条种族克制规则。每个单位都有独立抗性：1.0 = 完全免疫，正数 = 抗性，负数 = 弱点。
      例：火元素免疫火、怕冰；骷髅免疫毒素、弱神圣；魔像免疫奥术、怕雷；树精免疫自然、怕火。
      要加自己的魔法造物 / 元素怪物，只需在 CONFIG.heroes 里写 res 与 tags。


       传奇生物

      7 位传奇（炎竜 / 冰竜 / 巫妖 / 远古树精 / 不死鸟 / 石化蜥 / 死亡骑士）＋ 23 位精英（元素生物 / 魔像 / 灵体 / 圣骑士 / 德鲁伊 等）。
      传奇拥有锥形吐息（炎息冰息）、召唤亡者、根须领域、涅槃复活、石化凝视与常驻光环。


       点地释放的范围技

      许多技能可以指定地面施放：先出现预警圈，延迟后爆炸，能躲。
      另有锥形（吐息）、直线穿透（岩刺 / 狙击）、持续领域（毒云 / 雷电场 / 圣域）与召唤。


       元素体系与地形魔法

      五行 金 木 水 火 土，衍生 冰 光 暗 毒 雷 风，外加奥术 / 音波 / 物理  共 17 种伤害类型、19 条元素反应。

      基础魔法还能构造地形：石墙 / 冰墙 / 火焰地带 / 熔岩 / 荆棘丛 / 泥沼 / 圣光地。
      它们会真实地画在地图上、阻断道路或持续伤害，并带持续时间，到时自动消失。


       部署阶段（自定义站位）

      点「 开战」不会马上开打，而是进入部署阶段：拖拽蓝方单位摆放，或先点单位再点地面；
      也可以用「自动布阵 / 随机布阵」。满意后点「 开始战斗」。


       统帅 AI（团队作战计划）

      每支队伍有独立统帅：判断局势选择推进 / 固守 / 强攻，排出阵型
      （坦克在前、远程与治疗在后、刺客绕侧），指定集火目标和集结点，并会利用掩体与卡位。
      战场左上角实时显示双方姿态。


       节奏保障

      45 秒后进入 决死（全场伤害递增、治疗递减），70 秒后再加 战场崩坏（全场持续掉血），保证一定分出胜负。


      被标记的目标全队增伤，被嘲讽的敌人会强制转火；1.3 秒内多人打同一目标会触发合击。


       视角

      默认自动适配整张地图，全部单位永远可见；右下角小地图与右侧名单也始终显示每个人。
      滚轮 / 双指缩放，拖拽平移，点单位即可跟随。


       速度 / 操作

      右上「1.0」切换 0.5～4，「 暂停」随时停手观察。
      「配置」编队与技能，「地图」26 张地图随选（20 常规 + 6 爆破），「图鉴」查全部技能与反应。


       AI 训练（奖惩机制）

      AI 会按「模式目标」学习：竞技场=全歼、团竞=拼击杀、占点=抢点守圈、爆破=下包拆包。
      训练维度 11 项（进攻 / 目标 / 集火 / 风筝 / 掩体 / 技能 / 追击 / 生存 / 抱团 / 下包拆包 / 听指令），
      事件按重要度加权、按「离事件发生的时间远近」分配信用：普通事件 3 秒窗口，回合级事件 6 秒窗口。
      爆破新增细化事件：带包进点 / 下包成功 / 炸弹爆炸 / 拆包成功 / 守包到爆炸 / 清点夺回 / 3 秒内补枪；
      主信号是「回合胜负 + 下包 / 拆包 / 守包」，到集结位与抱团的小奖被压到 0.01~0.35。
      奖励按「信用分配」反哺到当时用到的策略权重（集火 / 风筝 / 掩体 / 生存 / 下包 / 进攻 / 跟队距离 / 指令点），
      跨对局累积并存档。HUD 左上角显示双方本场奖励，右上「训练」开关、「重置训练」清零。
      `node tools/check.js --aibench` 会让三组各跑 3 轮 16 回合 取中位数，训练组明显优于中性组才 PASS。


       创作工坊（DIY 规则）

      底部「创作」可直接用 JSON 添加 英雄 / 技能 / 装备 / 地图 / 地形 / 状态 / 反应 / 模式：
      填好点「校验并应用」即刻生效并自动存档，可导出备份、一键清空。
      控制台同样开放 defineHero / defineSkill / defineItem / defineMap / validateContent / exportContent。

       快捷装备 / 纯枪战（全模式）

      配置界面里的面板支持先勾选要改的项目（武器 / 护甲 / 饰品 / 盾牌 / 技能）并选好值，
      再点「确认应用」才生效，并会明确反馈「已修改 N 名单位」。预设按钮（全员配枪 / 按定位配枪 /
      纯枪战 / 恢复默认）只帮你勾好选项，仍需确认。


       抢点（占点）出生点优化

      第 1 个据点沿用常规出生带；从第 2 个据点起，阵亡单位在当前据点 10 格内、占领判定圈外的随机位置刷新
      （与据点连通、可站、无地形伤害、不被占位），复活就能立刻赶回圈里。


       爆破模式 AI 协作

      进攻方自由选择打 A 还是 B（按防守薄、距离近动态决定），也可以在任何包点下包；
      安装后全体 AI 都会知道（广播 + 名单/HUD 显示任务）。安装后：进攻方分工守包并优先打靠近/正在拆包的防守方；
      防守方分工直接拆包 佯攻吸引火力、让队友偷包 全歼进攻方后再拆（时间紧迫或只剩一人时全员强拆）。安装前守方优先卡住 3x3 包点入口、不越半场主动对枪，把「进点下包」与「守包拆包」拆成两个真正有取舍的阶段。

       爆破模式：炸弹与包点

      双方固定刷新在「两侧墙壁居中」的 3x3 起始位置里，炸弹就放在进攻方起始位置内，
      等进攻方自己走过去拾取；只有带包的人能安装炸弹。
      右侧名单会用「带包」标出谁拿着，HUD 也会显示「炸弹掉落待拾取 / 带包：谁 / 炸弹倒计时」。
      爆破模式全员血量与护甲统一（HP 100 / 护甲 5，召唤物除外），只比枪法与配合。


       爆破模式：屏障 + 地图正上方 15 秒强制读秒

      每回合开打前，地图正上方会挂一条读秒条（屏障 15.0s  0），同时战场上竖起两道屏障墙：
      红色进攻封锁线（自己的 3x3 起始位置往外数 5 格）与 蓝色防守封锁线（自己的起始位置往外数 4 格），
      墙后面那片半透明色就是禁区。谁都冲不过去：寻路、走位、冲刺 / 闪现 / 击退 / 拉拽全部被挡
      （越线那一步直接走不动），而且每个 tick 还会把越界的单位直接夹回线上
      撞墙时头顶会冒「屏障」两个字；准备阶段所有人都会跑到自己那道墙前面站定，抗不出去。

      读秒条和回合计时同步：15 秒走完屏障才消失（消失瞬间顶部闪「开战！」），回合计时这时才开始走；
      想提前出门是不可能的。


       每个角色都会喊话（日志 + 头顶标签）：进攻 A/B 点、绕后包抄、拾取炸弹、带队进攻、防守 A/B 点、游走支援、原地待命；
      附近同意同一条指令的同队角色自动组队（队长优先坦克/团队性高的），队里其他人没接敌时会跟紧队长；
      不同意的各自自由行动。名单里每人都有「攻/守 + 指令」小标签，日志会写「【指令】谁：什么 + 几人同意」。


       爆破地图（非对称 S&D  枪战逻辑）

      六张爆破图都是非对称的：离包点近的出生带是防守方，离包点远的出生带是进攻方（六张图的包点都在右侧，
      于是进攻方在左，防守方基地与 A/B 两个 3x3 包点在右侧）。
      地图用编织迷宫 + 错位掩体生成：没有长直线通道，进包点的路必须拐弯且沿途有掩体；
      A 与 B 之间没有直线联通（最短路会被强制折线化，转点要绕），但全图是连通的、可以自由转点。
      六张图结构各异（小镇街巷 / 仓库 / 双塔广场 / 大型炼油厂 / 地窖窄巷 / 训练场）。
      四回合为一节，节后攻防互换、两队物理换边（共 2 节 8 回合）：一节之内站位固定，不再每回合瞬移；
      进攻方永远站「离包点更远」的出生带，防守方守「离包点更近」的一侧。

      包点圆圈：下包区的活动范围就是那 3x3 格画面上会把 3x3 的格子框出来，圆圈半径 1.5
      正好内切居中在里面，一个格子都不外溢。

      观战布局：PC 自动铺满窗口；HUD / 操作按钮 / 单位详情 / 部署栏 / 击杀播报全部移出画布，地图只保留飘字与 toast。底部按键统一收进右下角，宽度与右侧队伍栏一致；日志在左下角。HUD 固定高度小占比：顶栏 30px / HUD 32px / 播报 22px / 底部 72px，低高度屏幕自动进一步压缩，地图始终占最大区域。配置 / 地图编辑 / 创作工坊统一全宽铺满（约 96% 窗口宽）；一键装备 / 预设下拉放在靠上位置，底部预留展开空间，选项不会向上弹。AI 护送包手时改为分散站位，减少挤团和窄道堵死。视野改为 5 格且有障碍遮挡；枪声、技能、爆炸、下包等声音会广播，AI 听到后会记录声源并过去调查；目标和包点不再直线冲中心，会先在外圈找掩体、避开扎堆和已知敌人方向，再走真正的 A* 路线。掩体收益提高，更会卡地形；视野/声音情报全队共享，没有全图透视；HUD/头顶指令会同步成当前实际行为；攻守双方都会通过掩体、下包拆包、回合胜负持续训练，每场结束胜方权重会蒸馏给败方，不断自对弈升级。

      音频 v4：支持单位坐标空间声像与距离衰减、战斗/UI/环境三总线；右上「音量」可调主音量 / 战斗 / 环境并自动存档；枪械、元素反应、爆破倒计时/下包/拆包/爆炸、UI 反馈与低血量心跳都有独立合成音色。默认整体音量更柔和，右上「音量」可单独调主音量 / 战斗 / UI / 环境；控制台运行 audioSelfTest() 可逐个试听。

      界面可读性：UI 小字统一放大 1.3 倍（叙述条、HUD、名单、日志、按钮、图鉴 / 工坊），浏览器自检会校验 computed 字号不小于 12~14px。

      角色大小：所有角色按标准格子大小绘制（1 个角色 = 1 格，字号 = 格子边长，格心对齐），
      地图上的地形 / 角色 / 特效 / 飘字全部统一到「格子中心」坐标系，不会再出现半格错位。

      三条路：每张爆破图都校验「进攻方起始位置  A / B」与「防守方起始位置  A / B」各有
      至少 3 条互不重叠的路，而且不能全是直线（生成时会自动补折线通道，出厂即合格）。



       为什么会掉血？

      点选单位后，详情面板有「最近受伤」显示来源。常见来源：崩坏（70 秒后全场持续掉血，HUD 有提示）、
      中毒/流血等持续伤害、岩浆/火海等地形。现在己方制造的地形只伤敌人，不再误伤自己人；圣光地只治疗己方。



      战后有详细数据与 MVP。碎片与连胜会自动存档。

       打完之后怎么继续

      对局结束时右上角「暂停」会变成「继续」，点它= 再来一场（爆破会重新回到「配置 -> 部署 -> 开始战斗」的完整流程，
      回合数/比分/攻守全部重置）；结果面板里的「再来一场 / 返回配置」同样有效。


       AI 现在会更主动

      防守方长时间没接触会派人巡逻 / 增援（不再全员站在包点正中央），守点站位改成包点外圈的卡位；
      进攻方队长没接敌时会等队友跟上来再压，减少一个人一个人的送；名单标签会实时显示
      「巡逻 / 等队友 / 跟队 / 下包 / 捡包 / 守点 / 增援」等状态。
