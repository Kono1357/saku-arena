# 朔の記憶闘技場

浏览器里直接开打的单文件实时对战游戏：两队各自带着 AI 上场自走互殴（「电子斗蛐蛐」auto-battler），
玩家负责配队伍、统装备、下指令、看戏。

**在线玩：<https://kono1357.github.io/saku-arena/>**

打开网页就是全部内容 —— 一个 `index.html` 里装着整款游戏：零外链、零依赖、零构建步骤。
地图、英雄、音效全是本地当场算出来的（音效是现场合成的音色，不带任何音频文件）。

## 有什么

- 4 种对局模式：竞技场（全灭制）/ 团竞 / 占点 / 爆破（S&D，下包·守包·拆包）
- 26 张地图（20 张常规 + 6 张非对称爆破图），每张都由地图生成器按种子算出来
- 57 位英雄，14 种「力之源」派系（追憶 / 守護 / 疾風 / 呪詛 / 共生 / 命運 …），技能 + 装备配置，含「快捷装备 / 纯枪战」一键统装
- 实时指令系统：AI 自己喊话下单（进攻 A/B、绕后包抄、守点、游走支援、增援…），3 秒内必刷新，头顶标签跟着变
- AI 训练：掩体 / 视野 / 声音情报全队共享，每场结束胜方权重蒸馏给败方，越打越强；「训练营」可自动连打
- 创作工坊：DIY 规则框架（自定义英雄 / 技能 / 地图，JSON 导入导出 + 校验报告）
- 游戏内地图编辑器：画笔 / 出生点 / 尺寸 / 存进地图库 / 导出 JSON
- 进度存在浏览器 localStorage（碎片 / 连胜 / AI 权重 / 自定义内容），换设备不跟着走
- 手机浏览器直接开：竖屏 390×844 / 360×740、横屏 844×390 都按手机重排过（状态条不再被压成 0 宽、地图占满主区、按钮给到手指尺寸）；双指缩放（以两指中点为锚点，手指落在单位上也照样缩放）、单指平移、松掉一根手指剩下那根继续拖；手机默认不显示右下角小地图（宽屏才显示），准备阶段面板收成「3+2 按钮 + 单位两行」不裁切
- 画面对比度按 WCAG 校准过：面板/边框/文字全部 ≥4.5:1（实测最低 4.82），地图不再是黑底 —— 地板亮度 0.021 → 0.211、墙体 0.613、整屏近黑像素 84% → 0%，障碍块带顶高光/底阴影，放大后还有格线纹理
- 手机上每个面板都跑满帧：地图库 26 张预览改成 canvas（一张图 1 个节点，整页 DOM 3.39 万 → 3350 个），整屏浮层打开时停掉背后的地图重绘，英雄卡点击不再重建整池（单次 160ms → 33ms）

## 玩法（30 秒上手）

1. 打开网址 → 读一遍自动弹出的「玩法说明」→ 开始游戏
2. 「配置队伍」：选模式 / 地图 / 双方英雄（可一键随机）
3. 需要的话进「装备配置」统装技能与枪械
4. 点「开战」；爆破模式会先进部署阶段（地图正上方 15 秒屏障读秒），跑完点「开始战斗」
5. 右上角常驻：暂停 / 倍速 / 音量 / 适配 / 缩放 / 跟随；打完在结果面板点「再来一场」
